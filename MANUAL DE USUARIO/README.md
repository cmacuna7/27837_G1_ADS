# Manual de Usuario (MU)

Este directorio contiene los documentos que forman parte del Elemento de Configuración del Software (ECS) relacionado con el manual de usuario del proyecto **Healthy+**.

## Información del ECS

- **Código del ECS:** MU
- **Nombre del ECS:** Manual de Usuario
- **Autor:** Marcelo Acuña, Abner Arboleda, Christian Bonifaz
- **Proyecto:** Healthy+
- **Línea base:** LBD - Línea Base Documentación
- **Tipo de ECS:** Documento (PDF)
- **Fecha de creación:** 01/02/2026
- **ID del proyecto:** 27837_G1_ADS

## Líneas Base Relacionadas

- **LBA - Análisis:** Contiene diagramas de actividades y documentación de análisis funcional y de procesos
- **LBC - Implementación:** Contiene código fuente frontend y backend del proyecto
- **LBD - Diseño:** Contiene diagramas de flujo y diagramas de casos de uso
- **LBR - Requisitos:** Contiene la especificación completa de requisitos y diagramas de flujo

## Contenido Principal

- Guía de instalación del sistema
- Manual de uso de funcionalidades
- Instrucciones paso a paso para usuarios finales
- Capturas de pantalla y ejemplos de uso
- Resolución de problemas comunes
- Preguntas frecuentes (FAQ)
