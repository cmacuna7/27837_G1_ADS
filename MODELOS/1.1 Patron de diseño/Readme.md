# Patrón de Diseño MVC (PAT)

Este directorio contiene los documentos que forman parte del Elemento de Configuración del Software (ECS) relacionado con el patrón de diseño del proyecto **Healthy+**.

## Información del ECS

- **Código del ECS:** PAT
- **Nombre del ECS:** Patrón de Diseño Modelo Vista Controlador
- **Autor:** Marcelo Acuña, Abner Arboleda, Christian Bonifaz
- **Proyecto:** Healthy+
- **Línea base:** LBD - Línea Base Diseño
- **Tipo de ECS:** Documento (PDF)
- **Fecha de creación:** 28/07/2025
- **ID del proyecto:** 27837_G1_ADS

## Líneas Base Relacionadas

- **LBA - Análisis:** Contiene diagramas de clases
- **LBC - Implementación:** Contiene código fuente frontend y backend del proyecto
- **LBD - Diseño:** Contiene diagramas de casos de uso
- **LBR - Requisitos:** Contiene la especificación completa de requisitos

## Contenido Principal

- Implementación del patrón Modelo-Vista-Controlador (MVC)
- Separación de responsabilidades
- Estructura de la aplicación
- Flujo de datos entre componentes
